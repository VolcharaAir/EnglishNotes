# Размещение EnglishNotes только на D:

По уточнённому требованию Windows-версия использует фиксированную папку
`D:\EnglishNotesData`, без перехода в AppData или на C: при ошибках.
В ней находятся база, WAL/SHM, блокировка экземпляра и временная папка приложения.
При недоступности D: запуск завершается сообщением об ошибке.

Исходники и виртуальное окружение размещайте в `D:\EnglishNotes`.
Данные находятся отдельно от исходников/будущего EXE.
`start.cmd` запускается двойным щелчком, проверяет размещение проекта на D:,
перенаправляет TEMP/TMP и отключает запись Python bytecode.
SQLite использует память для временных таблиц.

## Перенос на вашем компьютере

Доступа к вашему диску D: из облачной среды разработки нет. Эти действия нужно
выполнить на Windows; разработчик в облаке не выполнял их на вашем компьютере.

1. Закройте все экземпляры EnglishNotes.
2. Сохраните обновлённый архив исходников сразу на D: и распакуйте так, чтобы
   файл `pyproject.toml` находился в `D:\EnglishNotes`.
3. Если старая версия уже содержит ваши заметки, перенесите **всю** папку
   `%LOCALAPPDATA%\EnglishNotes` в `D:\EnglishNotesData`. Если папка назначения
   уже содержит базу, не объединяйте и не перезаписывайте её: сохраните обе копии
   и сначала определите нужную. WAL/SHM переносите вместе с базой.
4. Создайте новое виртуальное окружение на D: (старую `.venv` между дисками
   не переносите — внутри неё есть абсолютные пути).
5. Запустите обновлённую версию через `start.cmd`, убедитесь, что прежние занятия
   и тексты открываются и новые изменения сохраняются после перезапуска.
6. Только после этой проверки удалите оставшиеся старые копии проекта, архивов,
   виртуального окружения и папки `%LOCALAPPDATA%\EnglishNotes` на C:.
   Удаляйте только файлы EnglishNotes. Старый кэш установщика Python/pip может
   содержать файлы других проектов и автоматически не очищается.

Команды для разработчика, PowerShell (Python 3.14 должен быть установлен на D:):

```powershell
Set-Location D:\EnglishNotes
New-Item -ItemType Directory -Force D:\EnglishNotesData\temp | Out-Null
$env:TEMP = 'D:\EnglishNotesData\temp'
$env:TMP = $env:TEMP
$env:PIP_CACHE_DIR = 'D:\EnglishNotesData\pip-cache'
$env:PYTHONDONTWRITEBYTECODE = '1'
& 'D:\Python314\python.exe' -B -m venv .venv
.\.venv\Scripts\python.exe -B -m pip install -e ".[dev]"
.\start.cmd
```

`D:\Python314\python.exe` — пример пути к установленному на D: Python; укажите
фактический путь. Готовый EXE на текущем этапе по-прежнему не собирается.

Приложение управляет только собственными файлами. Windows, антивирус, браузер
и инструменты разработки могут независимо писать системные журналы, историю,
кэши или файл подкачки на C:. Гарантировать отсутствие **любых** записей ОС на C:
код приложения не может. Для будущего PyInstaller потребуется отдельно закрепить
распаковку runtime на D: либо выбрать сборку onedir; это пока не реализовано.
