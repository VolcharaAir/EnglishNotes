# EnglishNotes

Рабочая локальная основа Windows Desktop-приложения для заметок к занятиям английским.
Python 3.14+, PySide6, SQLite. Интерфейс на русском языке, текст заметок — на любом языке.

## Что работает

- Создание занятий, редактирование их названий, история в боковой панели.
- Создание нескольких заметок в каждом занятии, редактирование заголовков и текста.
- Удаление заметки после подтверждения.
- Автосохранение через 350 мс после изменения; при непрерывном вводе — каждые 2 секунды.
- Принудительное сохранение при переключении, создании записей и закрытии окна.
- Восстановление всех занятий и заметок из SQLite при запуске; открывается самое новое
  занятие и его первая заметка. Позиция курсора и выбранная заметка между запусками не сохраняются.
- Работа полностью без интернета. При первом запуске база и её схема создаются автоматически.
- Ошибка сохранения видна в окне. Текст остаётся в редакторе; переключение и закрытие
  блокируются до успешного сохранения. Можно скопировать текст и повторить сохранение.
- Второй экземпляр приложения для той же папки данных не запускается.

Автосохранение не защищает последние ещё не записанные символы при принудительном
завершении процесса или отключении питания. Уже подтверждённые сохранения записываются
транзакционно, с SQLite WAL и `synchronous=FULL`.

## Запуск из исходников — для разработчика

Windows: распакуйте проект в `D:\EnglishNotes`, используйте Python,
установленный на D:, и создайте виртуальное окружение там же. Точные команды,
порядок переноса старых данных и ограничения описаны в
[docs/move-to-d.md](docs/move-to-d.md). После подготовки запускайте `start.cmd`
двойным щелчком. EXE и облачное подключение на этом этапе не реализованы.

Linux для разработки и тестирования:

```bash
python3.14 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m englishnotes
```

Для воспроизводимой установки через uv: `uv sync --extra dev --locked`.
`uv.lock` фиксирует проверенные зависимости. Сам uv пользователю будущего EXE не нужен.

## Где лежат данные

На Windows: `D:\EnglishNotesData\englishnotes.sqlite3`.
AppData и C: не используются для данных приложения; автоматического запасного
пути нет. Временные файлы приложения: `D:\EnglishNotesData\temp`.
Исходники/окружение размещаются отдельно в `D:\EnglishNotes`.

На Linux: `$XDG_DATA_HOME/EnglishNotes` или `~/.local/share/EnglishNotes`;
на macOS: `~/Library/Application Support/EnglishNotes`.
Рядом с базой во время работы могут находиться `-wal`, `-shm` и файл блокировки.
Для ручной резервной копии закройте приложение и скопируйте папку данных целиком.
Заметки хранятся обычным текстом в SQLite, шифрование на этом этапе не реализовано.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check src tests
.\.venv\Scripts\python.exe -m ruff format --check src tests
```

Тесты интерфейса используют настоящие виджеты Qt через pytest-qt с платформой `offscreen`
по умолчанию. Базы тестов находятся только во временных каталогах pytest.
Результаты и ограничения проверки приведены в [docs/testing.md](docs/testing.md).
Решения по архитектуре и будущей дистрибуции — в [docs/architecture.md](docs/architecture.md).

Подключение по коду, участники, авторизация, Supabase, сборка PyInstaller, GitHub Actions
и публикация в Releases отложены до следующих явно запрошенных этапов.
