# Windows и живой Supabase: подтверждение 17 ноября 2026

Пользователь выполнил проверки на своих Windows-компьютерах и предоставил вывод,
скриншоты и подтверждения. Агент анализировал их удалённо; Windows EXE не запускался
в облачной Linux-среде. Здесь отдельно отмечены автоматические и ручные результаты.

- Журнал сборки: Python 3.14.4, PyInstaller 6.22.3, Windows 11; Build complete.
- Статус релиза — Pre-release. macOS-сборка в этом этапе не создавалась.

Серверную миграцию v2, Before User Created hook и private-only Realtime настроил
владелец вручную. Он подтвердил enabled=true, auth_hook_ready=true,
emergency_stop=false и пять проверок запрета прямого доступа/прав hook.

## Живой интеграционный тест

Первый запуск остановился после восьми успешных проверок на private Realtime.
После добавления обязательного join_ref в клиент и безопасной диагностики
повторный запуск завершился `Live Desktop result: PASS`, 19 проверок:

1. Три независимые реальные Auth-личности.
2. Refresh после перезапуска сохраняет пользователя.
3. Создатель занятия зарегистрирован.
4. Второй пользователь подключается.
5. Неверное приглашение отклоняется.
6. Посторонний не читает занятие.
7. Посторонний не пишет в занятие.
8. Второй участник не завершает занятие владельца.
9. Private-подписки A/B разрешены.
10. Private-подписка C явно отклоняется.
11. Invalidation от B доставляется A.
12. A читает заметку B с сохранённым авторством.
13. Одновременная правка сохраняется как конфликт.
14. Выбранная версия передаётся второму участнику.
15. Offline-правка фиксируется локально.
16. Повторное открытие профиля сохраняет правку.
17. Очередь отправляется при восстановлении обмена.
18. Удаление синхронизируется.
19. Завершение занятия синхронизируется.

В скрипте offline означает отсутствие HTTP-вызовов при локальной правке.
Физическое отключение сети дополнительно проверено пользователем через EXE.

## Ручная проверка двух EXE

Пользователь подтвердил:

- На втором Windows-компьютере скачан один EnglishNotes.exe из GitHub Releases
  и запущен двойным щелчком; дополнительные файлы проекта не передавались.
- Второй экземпляр подключился к новому занятию по коду.
- Добавление текста первым и изменение вторым отображаются в обе стороны.
- На первом ПК интернет отключён, внесена тестовая правка, приложение закрыто
  и открыто без сети; правка сохранилась.
- После включения интернета статус стал «Подключено», очередь уменьшилась до 0,
  тестовая правка появилась на втором ПК. Все три признака подтверждены отдельно.

Промежуточный скриншот с «Нет связи» и очередью 1 относился к offline-состоянию;
он не считался подтверждением отправки. Финальное подтверждение получено после него.

Отдельная ручная проверка GUI-диалога конфликта на двух EXE не зафиксирована;
конфликты проверены клиентскими тестами и живым интеграционным скриптом.
Изоляция данных и квоты дополнительно проверялись в одноразовом PostgreSQL.
Преднамеренное исчерпание глобальных квот действующего Supabase не проводилось.

## Локальные проверки разработки

После исправления Realtime: 152 pytest проверки PASS, Ruff PASS. Включён тест
настоящего websocket-client со строгим локальным WebSocket-сервером, проверка
join_ref, ACK и исключения секретов из диагностических сообщений.
Это Linux-тесты; они не выдаются за Windows-проверку самого EXE.
